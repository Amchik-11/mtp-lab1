## Идея программы

Дневник помогает оценить регулярность чтения. Пользователь задаёт число
прочитанных страниц за последовательные дни, а программа подсчитывает:

- общее количество страниц;
- среднее за календарный день, включая дни без чтения;
- число дней, когда удалось почитать;
- максимальное число страниц за один день.

Данные обрабатываются в памяти и не сохраняются между запусками.
Зависимости: только Python 3 и его стандартная библиотека.

## Использование

Демонстрация на данных за неделю:

```console
python main.py
```

Свои записи за три дня:

```console
python main.py --pages 10 0 25
```

В этом примере прочитано 35 страниц, среднее — 11.7 страницы в день,
активных дней — 2 из 3, лучший результат — 25 страниц.
Можно передать любое положительное количество дней.
Ноль означает день без чтения. Отрицательные и нецелые значения не допускаются.
Справка по параметрам: `python main.py --help`.

## Устройство

`main.py` принимает аргументы командной строки и печатает отчёт.
`reading_stats.py` содержит функцию `summarize`, которая проверяет значения
и возвращает рассчитанные показатели. Для пустого списка модуль возвращает
нулевые показатели. Пользовательский ввод обрабатывается через `argparse`.
