## Назначение

Консольная программа хранит количество страниц, прочитанных в каждый день
недели. Модуль `reading_stats.py`, добавленный в ветке `feature`, рассчитывает сумму,
среднее за все дни, число дней с чтением и лучший дневной результат.
Используется Python 3, установка дополнительных библиотек не требуется.

## Запуск

```console
python main.py
```

Чтобы изменить записи, отредактируйте список `pages` в `main.py`.
Числа в нём — количество прочитанных страниц за последовательные дни.
